## Текущая модель и проверка

Gradient Boosting на 30%-ной выборке всего набора и случайном стратифицированном
разделении: validation F1-macro 0,615 на равном числе наблюдений каждого класса,
0,315 на всей validation с исходными пропорциями. Тот же случайный split, модель,
признаки и оценки: outputs/better_model_validation.csv и src/better_model.py.
Эти цифры не являются результатом test, не являются причинными выводами, не
гарантируют качества на будущих годах. В 200 000 сбалансированных train-строках
есть повторы; уникальных ID 139 365. Исторически часть строк 2021 года, ранее
использованных как validation, может попасть в новый случайный test или train;
такой test нельзя считать полностью независимым от всей разработки.
Нужен новый обоснованный финальный hold-out без повторного подбора по test.
