# Размещение на GitHub и сдача

Удалённый репозиторий ещё не создан. Локальный Git уже инициализирован.
Не загружайте исходный CSV, большие Parquet, SQLite, ML-выборки и joblib:
они исключены в .gitignore. Ссылки на данные и SHA-256 есть в README.
Небольшие проверенные таблицы метрик, аудит, графики PNG и агрегаты включены.

После создания пустого репозитория в своём аккаунте GitHub скопируйте его
HTTPS-адрес. Из терминала в папке проекта:

```bash
git remote add origin https://github.com/USERNAME/US-Traffic-Accidents.git
git push -u origin main
```

USERNAME замените на имя аккаунта. GitHub предложит авторизацию, если она
не настроена. Секретные токены не нужно вставлять в код или в чат.
Если remote уже добавлен, сначала проверьте `git remote -v`.

Откройте страницу репозитория и убедитесь, что доступны README, src,
US_Accidents_Colab.ipynb, requirements.txt, docs и deliverables.
Проверьте ноутбук в новом сеансе Colab: Runtime → Disconnect and delete runtime,
затем Run all. Начало без кэша действительно проверяет скачивание и полный ETL.
После проверки сохраните outputs и проверьте основные метрики против отчёта.

Moodle: загрузите отчёт и презентацию минимум за 2–3 дня до итогового экзамена.
Дату экзамена нужно сверить с расписанием. Репозиторий должен быть доступен
преподавателю, а тема утверждена. Участники подтверждают фактический вклад.
